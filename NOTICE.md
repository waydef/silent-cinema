# third party material

## animated noto emoji

the reaction pictures in `public/emoji/` (`*.webp` animations and `*.svg` stills) are google's animated noto emoji from https://googlefonts.github.io/noto-emoji-animation/, licensed under creative commons attribution 4.0 (https://creativecommons.org/licenses/by/4.0/). the animations were scaled down to 128 px and re-encoded as webp; the svg files are unchanged.

## hls.js

the player loads `hls.min.js` from the `hls.js` npm package (https://github.com/video-dev/hls.js), apache license 2.0. it is served from `node_modules` and not copied into this repository.

## ws

the websocket server is the `ws` npm package (https://github.com/websockets/ws), mit license.
